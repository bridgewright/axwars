## A. 보고 대상 (시행세칙 제7조의4 ①)

다음 중 하나면 보고 의무:
1. 정보처리시스템·통신회선 장애로 — **가.** 전자금융업무 지연·중단 **30분 이상**, 또는 **나.** 지연·중단 **10분 이상 + 가입자 1만명 이상**
2. 전산자료·프로그램의 조작 및 오류 관련 사고
3. 전자적 침해행위로 시스템 사고 발생 또는 이용자 금전피해 통지
4. 전자금융거래법 제9조1항 사고

**제외(②)**: ① 1개 영업점 국한 중단·지연, ② 단순 정보제공 공개 웹서버 등 무관 장애, ③ 법9조1항1·3호 사고 중 사고금액 100만원 미만.

## B. 보고 단계·시한 (③④)

| 단계 | 시한·방법 |
|---|---|
| 최초보고 | 인지·발견 후 **24시간 이내**, **EFARS**로. 부득이 시 서면·팩스·유선 후 즉시 EFARS 재보고 |
| 중간보고 | 보완 필요 시 즉시. 조치완료까지 2개월 이상 → 인지일로부터 2개월 이내 + 종결까지 매 6개월. (2개월 미만 종결 시 생략 가능) |
| 종결보고 | 원인·조치·재발방지(+배상책임 시 배상조치) 완료, 정상업무 복귀 시. (최초보고 시 조치완료면 생략 가능) |
| 일괄보고(예외) | 법9조1항1호 사고 중 사고금액 3억원 미만은 매월분을 익월 15일까지 별첨2로 일괄 |

## C. 서식 기재 항목 — 별지 제2호서식 「별첨1: 정보기술부문 및 전자금융 사고내용」

| 구분 | 기재 항목 |
|---|---|
| 보고형태 | □ 최초  □ 중간  □ 종결 |
| 사고유형 | 침해사고 / **전산장애사고** / 전자금융사기사고 중 택1 + 세부 분류 |
| └ 전산장애사고 세부 | □ 업무처리 프로그램 오류(로직 오류 / 데이터 오류) □ 시스템 장애(서버·네트워크장비·스토리지·보안장비 / OS·DBMS·미들웨어·네트워크·보안·WAS) □ 시설·설비 장애(전원공급 차단·통신회선 훼손 등) □ **외부요인으로 인한 장애(클라우드 업체·통신업체·제휴업체 등)** □ 미정(파악 중) |
| └ 침해사고 세부 | 1.공격 대상(내부망/DMZ/기타/미상) 2.공격 방법(악성코드/DDoS/취약점 해킹/무단접속·조작/공급망 침해/기타/미상) 3.공격 피해(서비스 중단/정보유출/중요정보 조작/금전손실/기타/미상) |
| 최초 인지 | □ 금융회사  □ 고객(민원인)  □ 기타 |
| 일시 | **사고인지일시 / 사고발생일시 / 사고종료일시** |
| 피해 | 피해자 성명 / 생년월일 / 피해금액 |
| 금액 | 배상금액 / 배상인원수 / **사고금액 / 사고 영향 이용자수** |
| 시스템 | **사고발생 업무(시스템)명** |
| 내용 | **사고내용(현상 및 결과)** |
| 원인 | **사고원인(변경시점 및 사유 등)** |
| 영향 | **파급영향(영향받은 금융회사 등 / 외부요인으로 인한 장애 / 사고 원인 회사명)** |
| 조치 | **처리결과 / 대책(재발방지)** |
| (침해사고 선택) | 공격 유형(DDoS/파밍악성코드/C&C서버/기타) · 공격방법 · 공격자IP · 공격자MAC · Domain정보 · 상세내용 |

> ★ 카카오페이증권 장애 특성상 **'외부요인으로 인한 장애 / 사고 원인 회사명'** 칸이 핵심 — 미국 현지 브로커(예: 드라이브웰스) 연계 장애를 이 칸에 명시하게 되어 있다.
