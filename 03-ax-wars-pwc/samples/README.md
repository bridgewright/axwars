# samples — 실제 산출물 모음 (실행 없이 기능 이해하기)

이 폴더는 **플러그인을 직접 설치·실행하기 어렵거나, 회계 배경지식이 없는 분도** 결과물만 보고 두 스킬이 무엇을 해 주는지 이해할 수 있도록 만든 **실제 산출물 모음**입니다. 아래 파일은 모두 실제 엔진과 챗봇을 돌려 나온 결과를 그대로 담았습니다.

## 무엇을 보면 되나요

### 1. 트랙 1 — 시산표 변환 (`track1-converter/`)

일반기업회계기준 시산표를 넣으면 K-IFRS로 바꿔 주는 변환 도구의 실제 입력과 산출물입니다.

| 파일 | 무엇 |
|---|---|
| `input_trial_balance.csv` | 입력 — 소스 GAAP 시산표(계정과 금액) |
| `input_adjustments.json` | 입력 — 측정조정용 보조자료(연령표·리스 스케줄 등) |
| **`difference_analysis.md`** | **여기부터 보세요.** 계정·조정마다 IFRS 조항 **원문 근거(코퍼스에서 그대로 인용)** + 차이 + 판단 논리 + 분개 파급효과(자산·부채·자본·손익이 얼마 움직이는지)를 단위와 함께 설명 |
| `ifrs_financials.xlsx` | 산출 — 변환된 K-IFRS 재무상태표·손익계산서 |
| `reconciliation.xlsx` | 산출 — 전환조정 명세서(재분류·조정별 소스→IFRS·금액·근거) + 자본 전환 브릿지 |
| `impact_analysis.xlsx` | 산출 — 자본총계·순이익 등 소스 대비 IFRS 변화 |
| `result.json` | 산출 — 기계판독용 결과 |

핵심으로 볼 것: `difference_analysis.md`의 각 조정에 붙은 **"IFRS 근거 (코퍼스 원문)"** 인용. 손으로 쓴 요약이 아니라 실제 기준서 원문을 그대로 가져와 근거로 답니다. 이 예제에서는 여섯 개 측정조정을 계산해 자본총계가 5천만에서 5,634만으로 바뀝니다.

### 2. 트랙 2 — 회계기준 원문 챗봇 (`track2-chatbot/`)

`lease-recognition-QA.md` — 챗봇에게 "리스를 언제·어떻게 인식하나, 일반기업회계기준과 뭐가 다르냐"고 물었을 때의 **실제 답변을 그대로 캡처**한 예시입니다.

핵심으로 볼 것: 규정 내용은 전부 **원문 인용 + 출처 표기**, 챗봇이 얹은 해석·비교는 **`(일반 해설)` 라벨**로 원문과 분리됩니다. 근거를 못 찾으면 "근거 없음"이라 답하고 지어내지 않습니다.

## 직접 돌려 보려면

- 트랙 1: `src/gaap-ifrs/`에서 `gaap-ifrs convert --input <시산표> --source-gaap K-GAAP --extra <보조자료> --out out/`
- 트랙 2: 플러그인을 Codex에 설치한 뒤 대화형 `codex`에서 회계기준을 질문하면 챗봇이 자동으로 원문을 검색해 답합니다.

자세한 설치·실행은 최상위 `README.md` 참조.
