# 배포 원가 가정 — 채널톡 배포팀 표준 (제시가 산출용)

> 배포 계획서 6장(도입 원가 & 제시 가격)을 산출할 때 쓰는 **채널톡 배포팀 내부 가정**이다.
> 이 수치는 고객 인터뷰에서 나오지 않는다 → 여기 가정과 인터뷰가 캐낸 연동 공수를 곱해 계산한다.
> 아래는 **표준 가정치(샘플)**이며, 실제 프로젝트에서는 배포팀 확정 단가·영업 견적으로 대체한다. 보고서에는 "가정 기반 개략치"임을 반드시 명시한다.

## 1. 인력 단가 (원가 기준, 마진 제외)

| 역할 | 월 원가 | 일 단가(20영업일) | 비고 |
|---|---:|---:|---|
| 배포 컨설턴트 / 솔루션 엔지니어(SE) | 800만원 | 40만원 | 요건 정의·지식 세팅·연동 설계·검증·온보딩 주도 |
| 연동 지원 개발자 | 1,000만원 | 50만원 | 채널톡 측 태스크 연동·엔드포인트 검증 |

- **고객 측 개발 인력**은 고객 부담이므로 채널톡 원가에 포함하지 않음. 다만 6장에 "고객 측 필요 인력"으로 별도 표기(자체 API를 여는 개발자 등)
- PM·QA·오버헤드는 프로젝트 인건비의 **15%**로 일괄 반영

## 2. tier별 표준 소요 (채널톡 측)

| 연동 tier | 상황 | SE | 지원 개발 |
|---|---|---:|---:|
| `no_integration` | FAQ/RAG[^rag] 지식 세팅 | 0.5주(2.5일) | — |
| `workflow` | 조회·분기, 기성 커넥터 | 0.5주(2.5일) | 0~3일 |
| `system_task` (고객 자체 API 존재) | 실제 처리, 안전 엔드포인트 | 2주(10일) | 2주(10일) |
| `system_task` (외주 솔루션/복잡: WMS·PG[^pg]) | 위 + 외부 규격 대응 | +1주 | +2~3주 |

- 여러 태스크를 한 배포에 묶으면 지식·조회 작업은 연동 기간에 **병렬 흡수**되는 경우가 많음 → 단순 합산이 아니라 병렬 가정으로 총 기간 산정

## 3. 라이선스 (월 구독 · 고객 부담 · 채널톡 반복 매출)

- 채널톡 좌석 요금(그로스/엔터프라이즈, 좌석 수 기반) + 알프[^alf] 사용료(월정액 번들 또는 AI 상담 처리 건당 과금)
- 요금은 공개 요금제 기반 **개략치**이며 실제는 영업 견적으로 대체. 좌석 5석 + 알프 번들 기준 월 150만~250만원 수준으로 가정
- 프로페셔널 서비스(1회성 배포 원가)와 **구독(반복 매출)**을 분리해 제시

## 4. 제시가 산출식

- **원가(Cost)** = Σ(역할별 투입일수 × 일단가) × 1.15(오버헤드)
- **최소 제시가(Floor Price)** = 원가 ÷ (1 − 목표마진율), **목표마진율 35%** → 마크업 계수 약 **1.54**
- 제시가는 프로페셔널 서비스 원가에만 적용. 구독료는 별도 라인으로 표기
- 계산은 보고서에 **산식 그대로 노출**(예: `SE 15일 × 40만 = 600만`)해 감사 가능하게 함

## 5. 워크된 예시 (무브온 1차 도입 — 참고)

1차 범위: 지식 세팅(재입고·소재) + 배송조회 + 조건부 교환/취소 접수(자체 API 2주)

- SE: 지식·조회는 연동 기간에 흡수 → 총 3주(15일) × 40만 = **600만**
- 지원 개발: 자체 API 태스크 연동·검증 2주(10일) × 50만 = **500만**
- 인건비 소계 1,100만 × 1.15(오버헤드) = **약 1,265만** (원가)
- 최소 제시가 = 1,265 ÷ 0.65 = **약 1,950만원** (반올림 1,900만~2,000만)
- 구독(월): 좌석 5석 + 알프 번들 **월 150만~250만** (별도, 반복 매출)
- 고객 측 필요 인력: 자체 API 오픈·권한 담당 개발 1인 × 약 1주 + 지식 정비 담당 1인 × 1~2일

2차(회수 WMS·환불 PG): 지원 개발 +2~3주, SE +1주 → 원가 약 1,090만 → 제시가 **약 1,700만**

[^rag]: RAG — 문서·FAQ 같은 지식 자료를 AI가 실시간으로 찾아 근거로 삼아 답하게 하는 방식
[^pg]: PG(결제대행) — 카드 결제·환불을 처리하는 외부 결제 사업자. WMS는 물류·회수를 담당하는 창고관리시스템
[^alf]: 알프(ALF) — 채널톡의 AI 상담 에이전트. v2부터는 답변뿐 아니라 예약·주문·취소·교환 등 실제 처리(Task)를 수행함
