## 1. 도입 적합성
- 팀 규모: 미확인 (CS팀 별도) · 하루 상담량: 미확인 · 채널: 채팅

## 2. 자동화 범위 (우선순위 순)
- **구독 조회/취소** (적합도 high, 우선순위 1) — 현재: 상담사가 어드민 처리
- **환불** (적합도 low, 우선순위 2) — 현재: 상담사가 PG 통해 처리

## 3. 연동 가능성 진단 (해결률 상한을 가르는 핵심)
- **구독 조회/취소** — tier `system_task` · 시스템 자체 회원·구독 백엔드(integrated) · API yes · inhouse · 공수 낮음(내부 API 엔드포인트 오픈)
- **환불(금액 계산 포함)** — tier `system_task` · 시스템 외부 PG(separate) · API yes · vendor · 공수 높음(PG 규격 대응 + 검토 2~3주)

> tier `system_task`가 있으면 백엔드 연동이 해결률 상한을 결정한다. `no_integration`만이면 FAQ/RAG 수준(해결률 상한 낮음).
